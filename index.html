Projects

Website – Manual and Automation QA

I performed quality assurance for a previously developed web application, working in a team environment under Agile Scrum methodologies. Project management was conducted through weekly sprints using Jira, with active participation in Scrum ceremonies such as Sprint Planning, dailys y Sprint Review at the end of each sprint.

I designed test cases for user stories following BDD methodology, based on defined acceptance criteria. Scenarios were created using Gherkin language to ensure tests were readable and understandable for the entire team. These were managed with AssertThat to maintain traceability between requirements, tests, and results within Jira. Tests were executed per user story, and results were recorded across both web and mobile environments.

During each sprint, functional testing was performed, followed by exploratory testing at the end of the cycle to identify defects not covered by the defined test cases. Detected bugs were reported in Jira and linked to the corresponding user story to ensure full traceability between requirements, tests, and defects.

At the end of each sprint, I managed the release in Jira and documented all delivery-related information in Confluence. This included complete test plan documentation, execution results, and the overall product quality status.

Following the release, I identified the application's core flows and automated the regression testing suite using Playwrith, Pytest, and Python. These tests were integrated into a Continuous Integration (CI) pipeline with Github Actions, configured to automatically run the regression suite on a weekly basis, aligned with the end of each sprint.

Portfolio QA – Web Developer & API QA Engineer

I developed a web portfolio using HTML5, CSS3, and JavaScript, integrating a form connected to an APIpowered by Supabase. I designed the database tables and performed SQL queries for inserting and retrieving test data from the form.

I performed API testing using Postman, creating tests for GET (read), POST (create), PATCH (update), and DELETE (delete) requests. I implemented test scripts to validate positive, negative, and authentication response codes, as well as ensuring the correct structure and content of the response bodies.

Additionally, I implemented a Continuous Integration (CI) pipeline with GitHub Actions, configuring Newman to automatically execute the Postman test suites on every repository change.
